PANDUAN MENARUH FILE MOBIL 3D (.GLB):
=====================================
1. Anda bisa meletakkan file mobil 3D Anda di folder ini dengan nama:
   car.glb   (atau custom.glb)

2. Buka game seperti biasa (jalankan_game.bat).
3. Buka menu STORE (🛒 STORE).
4. Klik tombol "📁 LOAD FOLDER" atau gunakan tombol "📂 IMPORT FILE .GLB" untuk memilih file langsung dari komputer Anda.
5. Mobil 3D Anda akan langsung otomatis diskalakan, diberi lampu depan/belakang, underglow neon, dan api nitro!
